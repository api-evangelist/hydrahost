# Hydra Host

> Hydra Host is a bare-metal GPU cloud provider that rents and sells dedicated NVIDIA GPU servers (B200, H200, RTX 4090 and more) with full root access across 40+ global data centers for AI training, inference, and neocloud infrastructure. Its Brokkr platform ("AI Factory Operating System") exposes a single REST API to provision, terminate, and manage GPU fleets programmatically, with real-time inventory and single-tenant "Confidential Metal" compute.

This llms.txt was generated by the API Evangelist enrichment pipeline from the public Hydra Host surface (apis.yml + live probes). Hydra Host does not publish an llms.txt of its own.

## API

- [Brokkr API overview](https://docs.hydrahost.com/docs/brokkr-api-overview): Provision, terminate, and manage GPU fleets across every data center and OEM hardware stack. Base URL https://brokkr.hydrahost.com/api/v1 (uri-path versioning). Public GPU inventory at GET /api/v1/inventory.
